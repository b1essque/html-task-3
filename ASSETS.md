# Ресурсы

- `public/assets/campus.svg` — иллюстрация, созданная специально для этого учебного задания. Разрешены использование и изменение в учебных решениях.
- `public/assets/PTSerif-Regular.ttf` — PT Serif Regular, ParaType. Источник: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ptserif). Исходный файл: `PT_Serif-Web-Regular.ttf`. Лицензия SIL Open Font License 1.1 приведена в `public/assets/OFL.txt`.

Все ресурсы лежат в репозитории. Для работы сайта после скачивания проекта не требуется доступ к внешним сервисам.
